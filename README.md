# 2D Pixel Rougelike Game (Java)

A handmade 2D pixel-style game built with Java, featuring tile based rendering, animated environments. 
This project is a personal playground for learning and building a full-featured indie-style game from the ground up.

---

## Current Features

- Player movement with walking & idle animations
- Player camera tracking
- Tilemap rendering
- Collision detection with certain objects
- Implemented tiles:
  - River
  - Cave
  - Wooden bridge
  - Flower field
  - Early structure of ancient ruins
- Animated tiles (e.g., flowing river)
